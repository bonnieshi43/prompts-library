# 1 Feature Summary

**核心目标**：将所有图表类型（柱状、折线、面积、散点、蜡烛、箱线、雷达、树图、旭日图、层级图、马赛克图）的入场动画时长、缓动函数与元素间隔（stagger）节奏统一，对齐 swaker look-and-feel 设计参考，消除各图表类型间动画风格不一致的问题。新增面积图鼠标就近高亮交互功能。
**用户价值**：提升仪表盘中多图表动画的视觉一致性和专业观感；解决动画播放期间 hover 高亮/变暗效果与动画本身冲突导致的视觉闪烁问题；折线图、面积图新增 hover 高亮/变暗交互能力。

# 2 Test Focus

只列 **必须测试的路径**

## P0 - Core Path

核心功能
- 各图表类型动画时长（0.8s）、缓动（ease-out）统一生效
- 柱状图默认淡入效果（而非旧"生长"效果）渲染正确
- 面积图鼠标就近高亮功能正确
- `.ready` 门控：动画播放期间 hover 变暗不应触发，动画结束后（约 0.9s）hover 应正常生效

## P1 - Functional Path

- 边界情况：单系列/单数据点图表的动画（尤其 Mekko 单行/单列除零边界）
- 异常输入：数据点数量剧烈变化（1 个 → 大量）时 stagger 节奏表现
- 多对象交互：分面（多面板）面积图的高亮不跨面板串扰
- UI状态变化：视图快速切换后 hover 高亮仍然可用

## P2 - Extended Path （按需测试）

- 性能：面积图多系列、多分面、高频鼠标移动场景下性能表现
- 兼容性：移动端/触屏设备下面积图交互降级表现
- 安全：无相关安全风险

# 4 Special Testing

仅当 Feature 需要测试时执行。

## Security

无相关安全风险

## Performance

- 面积图新增鼠标移动时对每个系列做二分查找（每次最多25次路径采样），多系列、多分面、高频移动场景下需验证性能表现

## Compatibility

- 移动端：面积图新增基于mousemove的交互，触屏设备无原生对应事件，需验证该功能在触屏端是否有替代方案或仅对桌面端生效、不引发异常

## 本地化

无用户可见文本变更，无需本地化测试

## script

未新增Viewsheet脚本API，无需script兼容性检查

## 文档/API

若用户文档/培训材料展示了柱状图旧"生长"动画效果截图，需确认是否需同步更新

## 配置检查

`BAR_GROW_ENABLED`等为Java编译期常量，非SreeEnv属性，无需环境属性/重启验证
