# 1 Feature Summary

**核心目标**：为雷达图（Radar/Spider Chart，底层 `PolarCoord` + 内嵌 `ParallelCoord`）新增"蛛网状"多边形网格外观选项，将默认的圆形同心圆网格及外边界，替换为与维度/度量个数相匹配的 N 边多边形（如6个维度→六边形，5个→五边形）。
**用户价值**：满足体育统计、KPI/绩效仪表盘等场景下用户对"经典雷达图"外观的诉求（业界惯用多边形蛛网网格而非圆形网格），解决当前系统雷达图网格样式单一、不符合行业惯例的痛点。

# 2 Test Focus

只列 **必须测试的路径**

## P0 - Core Path

核心功能
- 通过脚本 `setWebGrid(true)` 开启蛛网多边形网格，雷达图网格环与外边界正确渲染为 N 边多边形
- 多边形顶点与对应 spoke（轴线）精确对齐，网格与边界顶点重合
- 未调用 `setWebGrid`（默认 `false`）时渲染效果与升级前完全一致

## P1 - Functional Path

- 边界情况：维度数小于 3（1或2个度量）时的表现
- 异常输入：在非雷达图（饼图/环形图）上误设置该属性
- 多对象交互：脚本同时设置轴线颜色/网格颜色/线型
- UI状态变化：度量个数动态变化时多边形边数随之更新

## P2 - Extended Path （按需测试）

- 性能：无明显性能影响
- 兼容性：向后兼容（升级前创建的图表）
- 安全：无新增安全风险点
